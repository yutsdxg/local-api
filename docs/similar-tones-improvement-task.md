## タスク
- similar-tonesの類似音色検索の精度を改善してください。アイデアは以下です。

## 改善のためのアイデア
- 音色の特徴データの抽出、算出をオーディオファイルの特定部分に限定する
- 限定方法
    - オーディオファイル中のレベルが最大のポイント(位置)で抽出対象にする
        - 音色の特徴が一番大きいと考えられるポイント
    - 音色変化の影響を受けない時間かつ、音色の特徴量を十分に決定できる時間サイズを抽出対象とする
    - 限定の仕方はインデックス作成時も、類似検索時も同条件で抽出する
    - 追加のアイデアとしてレベルが最大のポイントとは別にもう1ポイントで抽出してさらに精度を上げることも検討
        - レベルが最大のポイントが音色が明るくなると考えられるため、追加のもう1ポイントはレベルが低い、つまり音色が暗くなるポイントとする

## 期待する効果
- 音色の時間変化の影響を受けにくく、より音色に特化した類似検索を行うようにする
