# similar-tones ピッチ正規化対応

## 背景
- インデックス化されるファイルは「プリセットプレビュー」と呼ぶ
- プリセットプレビューはピッチが揃っている前提（例: 多くはC3、ベースはC1）
- `target_path` 側の素材ピッチが異なると類似度が下がる可能性がある

## 目的
- 検索時にターゲットのピッチを基準音へ寄せて比較できるようにする
- ベース素材の場合はC1へ、通常素材はC3へ寄せることを基本方針にする

## 方針
- 検索時にターゲット音源のみピッチシフトを適用する
- インデックスは「プリセットプレビュー」を基準ピッチで作成する前提を維持する
- ベース判定はユーザー指定パラメータで切り替える

## 追加仕様案
- `/audio/similar-tones/search` に `preset_type`（例: `normal` / `bass`）を追加
  - `normal` -> ターゲットをC3基準に寄せる
  - `bass` -> ターゲットをC1基準に寄せる
- もしくは `target_pitch` / `reference_pitch` を直接指定できるパラメータを追加

## 実装候補
- `AudioLoader` もしくは検索前処理でピッチシフトを適用
- 使用ライブラリは `librosa.effects.pitch_shift` を想定
- ピッチ推定の自動化は後回し（まずは手動指定）

## 検討事項
- ピッチシフト時のアーティファクト影響
- C1/C3以外の基準が必要になるケース
- 処理時間増加の許容範囲
